## TASK DESCRIPTION
Your task is to analyze a specific CLI command appearing in a {src_device} configuration
and determine **which secondary-level manual section** is most relevant to this command.

You must decide the best-matching econdary-level manual section based on:
- Command semantics and intent
- Command keywords and structure
- The functional scope implied by the manual directory hierarchy

You are NOT required to extract detailed explanations or parameters.
Your goal is classification, not documentation generation.

---

A snippet of {src_device} configuration text.
The configuration is provided for context only.

### TARGET_COMMAND
A single CLI command extracted from the configuration.
This is the command that must be classified.

## OUTPUT REQUIREMENTS
Return a SINGLE JSON object with the following fields:

- **"Command"**  
  The original TARGET_COMMAND string.

- **"Matched"**  
  Boolean value:
  - true if a relevant secondary section can be confidently identified
  - false otherwise

- **"Primary_Section"**  
  The name of the matched primary-level manual section (一级目录).  
  If not matched, set to null.

- **"Secondary_Section"**  
  The name of the matched secondary-level manual section (二级目录).  
  If not matched, set to null.

- **"Reasoning"**  
  A concise explanation describing **why** this command belongs to the selected secondary section.  
  The reasoning must be based only on:
  - Command semantics
  - Manual directory titles  
  Do NOT reference any undocumented behavior.

- **"Confidence"**  
  One of:
  - "High"   (clear semantic match to section title)
  - "Medium" (reasonable but indirect association)
  - "Low"    (weak match, possible ambiguity)
  - "None"   (no suitable section found)

---

## CLASSIFICATION GUIDELINES
- Prefer the most specific secondary section over generic ones.
- Use section titles as semantic signals, not keyword coincidence alone.
- Do NOT invent new sections or modify section names.
- Do NOT assume undocumented command behavior.
- If multiple sections seem applicable, choose the best one and lower the confidence level.

---

## FAILURE HANDLING
If no suitable secondary section can be identified:
- Set "Matched" to false
- Set "Primary_Section" and "Secondary_Section" to null
- Set "Confidence" to "None"

---
