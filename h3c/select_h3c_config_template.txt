## TASK DESCRIPTION
Your task is to identify the sections in the {tgt_device} configuration manual that are relevant to the given configuration.
You are given:
1) `CONFIG_TOC_TEXT`: the table of contents of the {tgt_device} configuration manual, organized by subtitles and section numbers.
2) `{src_device} CONFIGURATION`: a configuration snippet, where each line of configuration is annotated with a command-manual subtitle label (`<subtitle_label>::<command>`). These labels help indicate the command context as referred in the {src_device} command manual but may not directly match the {tgt_device} configuration manual’s structure.
3) `{src_device} CONFIGURATION MANUALS: the content of relevant {src_device} configuration manual.
4) `{src_device} COMMAND MANUAL`: the content of relevant {src_device} command manual.


Your goal is to identify which sections (subtitle + numbered entry in the table of contents) from the {tgt_device} configuration manual most likely describe the functionality used by the entire {src_device} configuration snippet.

## INPUT
### CONFIG_TOC_TEXT
{CONFIG_TOC_TEXT}

### {src_device} CONFIGURATION
{src_config}

### {src_device} CONFIGURATION MANUALS
{src_config_manuals}

### {src_device} COMMAND MANUAL
{src_cmd_manuals}

## YOUR TASK
- Determine the top sections in `CONFIG_TOC_TEXT` that explain the functionality implemented by the entire `{src_device} CONFIGURATION` snippet.
- Each section should be represented by the subtitle, section number (e.g. "2.3.1"), and section title. 
- The section number should be as detailed as possible(e.g. "2.3.1" instead of "2.3").
- Use all commands in the snippet collectively to infer the applicable configuration feature.
- The per-command subtitle labels (`<subtitle_label>`) are hints about command context but do not directly map to config manual sections; apply judgment to find functional sections.
- Always choose the most specific section that directly explains the configuration feature.
- Do not return parent sections if a more specific subsection exists.

## OUTPUT FORMAT
Return a JSON array, each entry representing one relevant config manual section:

[
  {
    "root_title": "...",
    "subtitle": "...",
    "number": "...",
    "confidence": "High | Medium | Low",
    "reasoning": "Explain briefly how this section matches the overall configuration snippet."
  },
  ...
]

- The "confidence" value reflects how strongly this section likely covers the snippet’s functionality.
- For each selected entry, the value of root_title must exactly match the corresponding grouped root title in the provided table of contents. Do not paraphrase or normalize it.
- If no sections are clearly relevant, return an empty list.
